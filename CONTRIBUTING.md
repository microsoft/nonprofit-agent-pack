# Contributing

This project welcomes contributions and suggestions. Most contributions require you to agree to a Contributor License Agreement (CLA) declaring that you have the right to, and actually do, grant us the rights to use your contribution. For details, visit [Contributor License Agreements](https://cla.opensource.microsoft.com).

When you submit a pull request, a CLA bot will automatically determine whether you need to provide a CLA and decorate the PR appropriately (for example, a status check or comment). Simply follow the instructions provided by the bot. You will only need to do this once across all repos using our CLA.

This project has adopted the [Microsoft Open Source Code of Conduct](https://opensource.microsoft.com/codeofconduct/). For more information, see the [Code of Conduct FAQ](https://opensource.microsoft.com/codeofconduct/faq/) or contact [opencode@microsoft.com](mailto:opencode@microsoft.com) with any additional questions or comments.

## What helps most

- **Issues** that describe a problem with an agent: the agent name and version, what you asked, what you expected, and what happened.
- **Improvements to the playbooks and skills** in [skills](skills), such as a clearer checklist item or a missing step in a method.
- **Ideas for new agents** for common nonprofit work. If you're building nonprofit agents, consider adding them to this pack instead of starting a separate one, so everyone gets the same tested methods.

## Before you open an issue or pull request

- **Don't include confidential or personal data**, such as client, donor, staff, or minor information, in issues, pull requests, or sample files. Use fictional data, and start sample file names with `DEMO`.
- **Agent files** in [downloads](downloads) are Copilot Studio solution exports. Describe the change you want in an issue instead of editing those `.zip` files directly; maintainers rebuild them for each release.
- **Keep the method honest.** Agents must cite their sources, show `[ADD: ...]` instead of inventing facts, and decline requests outside their job. Changes that weaken these rules won't be accepted.

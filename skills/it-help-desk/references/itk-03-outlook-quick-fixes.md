# Outlook Quick Fixes

> Generic Microsoft 365 help for the Nonprofit Agent Pack IT Help Desk. Some steps depend on settings your IT team controls. Replace or extend these articles with your own IT procedures.

- Missing emails: check the Focused and Other tabs, the Junk Email folder, and your rules. In new Outlook and Outlook on the web, go to Settings > Mail > Rules. In classic Outlook, go to File > Manage Rules & Alerts.
- Mailbox full: empty Deleted Items. Save large attachments to OneDrive and share them as links. Move old mail to Online Archive only if IT turned it on for you.
- Outlook not syncing: close and reopen Outlook, then check that you are online. Sign in to Outlook on the web at https://outlook.cloud.microsoft to see if your mail is arriving.
- Report a suspicious email: select the message, then Report > Report phishing. If you don't see Report, use the method IT provides.

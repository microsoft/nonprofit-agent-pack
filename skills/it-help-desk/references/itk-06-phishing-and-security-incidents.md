# Phishing and Security Incidents

> Generic Microsoft 365 help for the Nonprofit Agent Pack IT Help Desk. Some steps depend on settings your IT team controls. Replace or extend these articles with your own IT procedures.

## Signs of phishing

- Urgent requests for money, gift cards, passwords, or sign-in codes.
- A sender address that doesn't match the sender's name or organization.
- Unexpected attachments or sign-in pages.

## If you clicked a link or entered your password

1. Report it to IT right away. Treat it as urgent.
2. Change your password at https://myaccount.microsoft.com (Change password). If you can't sign in, reset it at https://aka.ms/sspr.
3. Report the message: select it, then Report > Report phishing.
4. Don't forward it to coworkers.

## Report it

- Report every suspicious message, even if you didn't click anything. Select the message, then Report > Report phishing. If you don't see Report, use the method IT provides.

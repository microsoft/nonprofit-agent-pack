# OneDrive and Sharing Files Safely

> Generic Microsoft 365 help for the Nonprofit Agent Pack IT Help Desk. Some steps depend on settings your IT team controls. Replace or extend these articles with your own IT procedures.

- Sync problems: select the OneDrive cloud icon in the taskbar, check for errors, and select Resume syncing if paused.
- Restore a deleted file: open OneDrive on the web and look in the Recycle bin. Work files are kept for up to 93 days unless your organization changed this.
- Share safely: use Specific people links. Set an expiration date where available. When the work is done, use Manage access > Stop sharing.
- Never store client or donor data in personal cloud accounts.

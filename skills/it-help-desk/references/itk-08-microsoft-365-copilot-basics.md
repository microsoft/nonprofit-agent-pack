# Microsoft Copilot and Copilot Chat Basics

> Generic Microsoft 365 help for the Nonprofit Agent Pack IT Help Desk. Some steps depend on settings your IT team controls. Replace or extend these articles with your own IT procedures.

- Microsoft Copilot Chat (formerly Microsoft 365 Copilot Chat): sign in with your work account at https://m365copilot.com (or https://m365.cloud.microsoft/chat). The green shield means enterprise data protection applies.
- Good prompts include a goal, context, the source to use, and the format you want.
- Always review Copilot's output for accuracy before sharing. Follow your organization's AI acceptable use policy.
- Agents in Teams: in Teams, select Apps, search for the agent (under Built for your org or Built with Power Platform), and select Add. Not there? Ask IT.

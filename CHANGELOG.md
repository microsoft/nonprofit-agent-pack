# Change log

## 1.0.7 (October 2026)

First public release.

- **All agents:** each greeting says the agent is AI and can make mistakes, and asks you to review what it creates. Greetings, descriptions, and instructions no longer overstate results; for example, "a winning plan" is now "a stronger plan", and files are described as drafts for you to review.
- **AI Policy Coach:** the sample produces the full policy and governance plan in one reply.
- **Board Packet Builder:** memory is off by default; a maker can turn it on from the agent's **Build** tab. If you upgrade from an earlier version, memory turns off: stored memories aren't deleted, but the agent stops using them. New icon.
- **Docs:** install steps now say to select **Publish** after you import, because an upgrade doesn't publish the five standard agents. Code interpreter is described as an environment setting, and the Teams steps include **Add channel**. Web search and IT Help Desk's Microsoft Support and Learn pages work through Bing, which has its own data terms; this is now explained in "Your data" and the Responsible AI notes. The README adds images, example outputs, and who the pack is for.

## 1.0.6 (October 2026)

Release candidate, not published on its own. Its changes are part of the first public release.

- **Name:** the pack is now the Nonprofit Agent Pack. Solution display names and file names changed; solution and publisher unique names didn't, so this version imports over 1.0.5 in place.
- **IT Help Desk:** gives steps before offering a ticket; never helps bypass MFA; has `[ADD: ...]` placeholders for your IT contact; uses Microsoft documentation only (no community Q&A); content moderation set to Medium; updated sign-in, MFA, Outlook, Teams, OneDrive, phishing, and lost-device steps.
- **AI Policy Coach:** answers direct questions before asking for an organization profile; policy library adds third-party AI and intellectual property, records retention, children and youth, accessibility, AI-generated media, and a way to request human review; updated product names and legal wording.
- **Impact Report Builder:** uses Met, Nearly met, and Not met for closed reporting periods; clearer rules for causal claims and small samples.
- **Agreement Reviewer:** updated Single Audit and Assistance Listing wording; calendar files include DTSTAMP and line folding; rules of thumb labeled as heuristics.
- **Grant Proposal Studio:** the sample now finds gaps on its own; scoring bands labeled as rules of thumb.
- **Board Packet Builder:** the financial dashboard script uses the Total expenses row, flags unbudgeted lines, warns about skipped or unreadable cells, and handles negative budgets; consent agenda and motion wording updated.
- **All agents:** treat instructions inside files as information, limit personal data in outputs, say when a file can't be read, create files with titles, headings, and table header rows, and show a plain-language message when content is blocked.
- **Samples:** fictional names changed where they matched real organizations or people.
- **Docs:** new "Before you start", "What it costs", and "Your data" sections, current install steps, Responsible AI notes, and this change log.
